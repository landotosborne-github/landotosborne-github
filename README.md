## Featured projects

| Project | What it shows |
| --- | --- |
| [**SKIPPY: Automated SE Test Bench**](https://github.com/landotosborne/skippy-se-test-bench) | Python socket/SCPI control of a signal generator and an in-enclosure spectrum analyzer. Full 100 MHz–6 GHz sweeps of thousands of points about once per second (vs. about 3 manual readings per minute), with a test-plan GUI, measurement-uncertainty math, automated reports and a results database. Technical write-up; the source belongs to MOS and isn't public. |
| [**Boltzmann's constant from Johnson–Nyquist noise**](https://github.com/landotosborne/johnson-noise) | UCSB advanced lab. Resistor thermal noise through a preamp, band-pass filter and spectrum analyzer at room temperature and 77 K; Python fits with error propagation to estimate k<sub>B</sub> and absolute zero. The report includes an error analysis of the gap to the accepted value. |
| [**Interactive 2D heat-equation simulator**](https://github.com/landotosborne/heat-equation-2d) | UCSB computational physics lab. Numba-accelerated finite-difference (FTCS) solver with a terminal UI, image-based shapes and stability checks. |
